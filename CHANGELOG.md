# Changelog

## [0.1.0] - 2026-11-19

### Adicionado
- Menu principal no Windows PowerShell 5.1.
- Diagnóstico básico do sistema via CIM.
- Consulta de rede local (adaptadores IPv4, gateway e DNS).
- Teste ICMP de conectividade com destino validado.
- Exportação de relatório JSON local, sem IP, hostname ou usuário.
- Auditoria simplificada de ações.
- Teste de integridade (smoke test) sem dependencias adicionais.
- Documentação de introducao, arquitetura, segurança e roadmap.

### Limitacoes
- Sem reparos ou alteracoes do sistema.
- Sem integração com nuvem/Intune ou execucao remota.
- Validacao funcional requer Windows 10/11 com Windows PowerShell 5.1.
